# 钱钱美甲工作台｜PWA 基础原型

这是可直接部署的移动端 PWA 原型。

## 已实现
- 首页 2×2 今日看板
- 今日预约时间轴
- 一键切换待确认 / 已完成 / 已取消
- 完成订单自动更新今日营收、顾客累计消费、技师业绩与完成单数
- 顾客、技师、服务项目基础数据页
- 移动端侧边栏
- PWA manifest + Service Worker
- 浏览器离线缓存
- 数据保存在浏览器 localStorage，刷新不丢

## 当前原型的边界
本包是“可运行基础原型”，云端实时同步、账号权限、真正的凌晨服务器归档、跨手机同步、AI行为学习需要接入后端数据库/认证服务后才能正式上线。
当前版本的数据是本机浏览器存储，不等于云端备份。

## 部署
将整个目录上传到任意支持 HTTPS 的静态网站托管服务，打开网址后即可“添加到主屏幕”。
HTTPS 是 PWA 安装和 Service Worker 正常工作的必要条件（localhost 开发环境除外）。
