钱钱美甲工作台 V7.0 全类目可编辑版

本版基于你上传的 V6.0 重新改造，核心目标：
每一个类目本身就是可操作的数据管理页面。

预约管理：新增、编辑、删除、状态修改
顾客数据库：新增、编辑、删除
会员扣卡：新增消费、编辑、删除
技师数据库：新增、编辑、删除
技师排班：直接修改班次
服务项目：新增、编辑、删除
产品数据库：新增、编辑、删除
记账流水：新增、编辑、删除
菜单选项：新增、修改、删除
系统设置：门店名、积分规则、自动记账、数据导出/导入

页面右下角还有一个“＋ 新增”快捷按钮，在对应类目页面直接新增。
空白类目会显示“立即新增”。
每一条数据右侧固定显示“✎ 编辑”和“删除”。

部署时只上传：
index.html
manifest.webmanifest

不要上传旧版 sw.js，避免旧缓存继续显示之前无法交互的页面。

GitHub Pages 更新后：
电脑 Ctrl+F5 强制刷新；
手机关闭旧网页再重新打开。
